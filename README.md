# Jimmi at the Gym — brand site draft

Static lookbook site: play Brock’s track, browse product cards, buy on Etsy.

## Preview

```bash
cd /workspace/jimmi-site
python3 -m http.server 8765
```

Open http://localhost:8765

## Swap Etsy links

Edit `products.js` — each product has an `etsyUrl`. Replace `https://www.etsy.com` with real listing URLs when the shop is live.

MP3 lives at `audio/jimmy-at-the-gym.mp3`. Cover art at `assets/cover.jpg`.
